👻 Ghost Mode Rules

🏆 How to Win

  • If only one participant finishes, they win.
  • If both finish, the higher score wins.
  • If neither finishes, the higher score wins.
  • Equal scores result in a draw.

⏱️ Race Rules

  • Each race lasts 30 seconds.
  • Both participants receive the same passage.
  • If one finishes early, the other can continue typing.
  • The race ends when both finish or time runs out.
